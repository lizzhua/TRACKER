# Brand Tracker

> 自動化品牌輿情追蹤與每日報告系統。

以 aespa 為示範品牌，彙整公開網路資訊並產生每日 HTML 儀表板，呈現提及內容、情緒分布、熱門關鍵字與偵測到的品牌事件。

## 解決的問題

品牌討論分散在不同來源，人工蒐集耗時且難以持續追蹤。本專案將每日蒐集、分類與報表生成流程自動化，建立可回溯的輿情資料庫。

## 功能

- 每日同步公開網路提及資料
- 初步標記正向、負向與中立情緒
- 偵測新品、促銷、活動與合作等事件
- 以圖表呈現情緒分布與熱門關鍵字
- 提供可搜尋的資料表與來源連結
- 產出可獨立開啟的 HTML 報告

## 技術重點

`HTML` · `CSS` · `JavaScript` · `Chart.js` · 搜尋資料整合 · 自動化報表生成

## 使用方式

在 GitHub 的 `reports/` 目錄選擇任一 HTML 報告，下載後以瀏覽器開啟。

## 限制與後續方向

- 搜尋結果是監測訊號，非完整網路資料。
- 情緒與事件分類應由人工覆核，特別是高風險或跨語言內容。
- 可進一步加入資料庫、來源可信度評分、告警門檻與可設定的品牌關鍵字。
